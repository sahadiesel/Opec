# คู่มือการใช้งาน พอร์ทัลลูกค้า (OPEC Client Portal)

เอกสารนี้อธิบายการเข้าใช้งาน **พอร์ทัลลูกค้า** ผ่านเว็บแอปหลักของ OPEC ที่ `**https://opec.co.th`** — ใช้ตรวจ **ใบเสนอราคา** ดู **สรุป timesheet** อนุมัติ **ใบแจ้งหนี้เรียกเก็บ** และพิมพ์ **ใบกำกับภาษี / ใบเสร็จรับเงิน** หลังชำระเงิน

---

## 1. การเข้าสู่ระบบ (Login)

1. เปิดเบราว์เซอร์ไปที่ `**https://opec.co.th`**
2. ที่หน้าเข้าสู่ระบบ ให้กรอก **อีเมล** และ **รหัสผ่าน** ที่ทีม OPEC หรือผู้ดูแลบัญชีของท่านจัดให้ (บัญชีประเภทลูกค้า — Customer portal)
3. กดเข้าสู่ระบบ
  - หากลืมรหัสผ่าน ใช้ลิงก์ **ลืมรหัสผ่าน / รีเซ็ตทางอีเมล** ตามที่หน้าเว็บแสดง (ส่งลิงก์ไปที่อีเมลที่ลงทะเบียนไว้)
4. หลังเข้าสำเร็จ ระบบจะพาไปยัง **พอร์ทัลลูกค้า** โดยอัตโนมัติ โดยเริ่มที่ **หน้าหลัก (Dashboard)**
  - URL จะอยู่ภายใต้เส้นทาง `/client-portal/...` เช่น `/client-portal/dashboard`

**หมายเหตุ:** บัญชีพนักงาน OPEC และบัญชีลูกค้าไม่เหมือนกัน — คู่มือนี้เฉพาะ **บัญชีลูกค้าที่เข้าได้เฉพาะพอร์ทัล**

---

## 2. ภาษาและการออกจากระบบ

- มุมบนขวามีปุ่มสลับภาษา **ไทย (TH)** / **English (EN)** และปุ่ม **ออกจากระบบ**
- ข้อความเมนูและคำอธิบายบางส่วนจะเปลี่ยนตามภาษาที่เลือก

## 5. ใบเสนอราคา (Quotations)

1. ไปที่เมนู **ใบเสนอราคา** แล้วเลือกรายการที่ต้องการ
2. ในหน้ารายละเอียดจะเห็นยอดรวม รายการบริการ และเงื่อนไข
3. **การพิมพ์:** กดปุ่ม **พิมพ์ (Print)** — ระบบจะเปิดหน้าต่างพิมพ์ของเบราว์เซอร์ จากนั้นใช้ **พิมพ์ (Ctrl+P)** หรือบันทึกเป็น PDF ได้
  - หากไม่มีหน้าต่างขึ้น ให้ **อนุญาตป๊อปอัป** สำหรับ `opec.co.th`
4. **การอนุมัติ (เฉพาะผู้อนุมัติ):**
  - **อนุมัติ** — รับข้อเสนอตามที่ปรากฏ  
  - **ไม่รับ** — ปฏิเสธใบเสนอราคา (มีขั้นตอนยืนยัน)  
  - **ขอแก้ไข / ต่อรอง** — ส่งข้อความให้ OPEC แก้ไขใบเสนอราคาใหม่
5. บัญชี **ผู้ดู** สามารถดูและพิมพ์ได้ แต่การกดรับ/ไม่รับต้องให้ **ผู้อนุมัติ** ดำเนินการ

หลัง **รับใบเสนอราคา** ฝั่ง OPEC/ฝ่ายขายจะดำเนินการเปิด **PO** ตาม workflow ภายใน (ไม่ได้ทำจากพอร์ทัลลูกค้าโดยตรงในทุกกรณี — ขึ้นกับข้อตกลงกับ OPEC)

---

## 6. Timesheet (สรุปลงเวลา)

1. ไปที่ **สรุปลงเวลา (รายเดือน)**
2. หน้านี้แสดงรายการตาม **PO / Wave / งวดเดือน** ที่ทาง OPEC เปิดให้ท่านตรวจ
3. กดเข้าไปดู **สรุปรายเดือน** หรือรายละเอียดตามที่หน้าจอแสดง — เป็น **ข้อมูลอ่านอย่างเดียว**
4. มีคำอธิบายเรื่องสถานะแถว (เช่น ตรวจจากสลิปกระดาษ, ล็อกแล้ว ฯลฯ) — ใช้เป็นหลักในการเทียบกับ **ใบเรียกเก็บ**
5. หากยอดไม่ตรงกับความเป็นจริง **ไม่ใช่** การแก้ไข payroll ในหน้านี้ — ใช้ช่องทาง **แจ้งปัญหา / ขอแก้ไขพิเศษ** ตามที่ปุ่มบนหน้าระบุ (เมื่อมี)

**ความเกี่ยวข้องกับการวางบิล:** หลังตรวจ timesheet แล้ว ขั้นตอนถัดไปคือไปที่ **การเงินและเอกสาร** เพื่อตรวจ **ใบแจ้งหนี้เรียกเก็บ** และยืนยันหรือแจ้งข้อโต้แย้ง

---

## 7. การเงินและเอกสาร — ใบแจ้งหนี้ & ใบกำกับภาษี

เข้าที่เมนู **การเงินและเอกสาร** (`/client-portal/accounting`) จะมี **สองแท็บหลัก**

### แท็บที่ 1: **ใบแจ้งหนี้**

- แสดง **ตารางรวม** ทั้ง  
  - **ใบแจ้งหนี้เรียกเก็บ (Commercial invoice)** — เลขที่ประมาณ `DFI-…` หรือรูปแบบที่ OPEC กำหนด  
  - และ **ใบกำกับภาษี (Tax invoice)** — เลขที่ตามที่ออกจากระบบ
- **กดที่แถว** หรือปุ่มลูกศร เพื่อเปิดรายละเอียด

**ใบแจ้งหนี้เรียกเก็บ (รอลูกค้าตรวจ):**

- เปิดหน้ารายละเอียด → ตรวจยอดก่อน VAT / VAT / รวม  
- **พิมพ์:** กด **พิมพ์** ได้ทันที (ก่อนหรือหลังยืนยัน ตามที่ระบบอนุญาต)  
- **ยืนยันยอดเรียกเก็บ:** ปุ่ม **ยืนยันยอดเรียกเก็บ** แสดงเฉพาะเมื่อสถานะ **รอตรวจ** และบัญชีเป็น **ผู้อนุมัติ**  
- หากไม่เห็นด้วยกับยอด ใช้ปุ่ม **แจ้งข้อโต้แย้ง / ทักท้วง** เพื่อส่งข้อความให้ OPEC แก้ไขก่อนให้ยืนยันอีกครั้ง

**ใบกำกับภาษี / ฉบับร่าง:**

- แถวที่เป็นใบกำกับภาษี — กดเข้าไปจะไปหน้าที่เหมาะสม  
  - หากเป็น **ร่างที่รอท่านตรวจ** อาจเปิดหน้าร่าง  
  - หาก **ออกแล้ว (ISSUED)** จะเปิดหน้า **พิมพ์ใบกำกับภาษี / ใบเสร็จรับเงิน**
- บนหน้านั้นมีปุ่ม **พิมพ์** — เปิดหน้าต่างพิมพ์มาตรฐานของ OPEC (เอกสารฉบับเดียว รวมใบกำกับกับใบเสร็จในรูปแบบที่ระบบกำหนด — **ไม่ใช่ e-Tax** จากกรมสรรพากรโดยตรง)

### แท็บที่ 2: **ใบกำกับภาษี/ใบเสร็จรับเงิน** (รายการรับชำระ)

- เน้นแสดง **รายการที่บันทึกว่ารับชำระแล้ว** — เลขที่อ้างอิง วันที่ ยอดเงิน  
- หากมีการเชื่อมกับใบกำกับภาษี จะมีปุ่ม **เปิด / พิมพ์** เพื่อไปหน้าพิมพ์เอกสารใบกำกับภาษี–ใบเสร็จอีกครั้ง

**สรุปเส้นทางพิมพ์ใบกำกับภาษีหลังโอนเงิน:**

1. ฝ่ายบัญชี OPEC บันทึกการรับชำระและออก/อัปเดตเอกสารตามขั้นตอนภายใน
2. ท่านเข้า **การเงินและเอกสาร**
3. ไปที่แท็บ **ใบแจ้งหนี้** เพื่อเปิดแถว **ใบกำกับภาษี** ที่สถานะออกแล้ว — **หรือ** ไปที่แท็บ **ใบกำกับภาษี/ใบเสร็จรับเงิน** เพื่อเปิดจากรายการรับชำระ
4. กด **พิมพ์** แล้วใช้คำสั่งพิมพ์ของเบราว์เซอร์

---

## 8. ข้อควรระวังเรื่องการพิมพ์

- ปุ่ม **พิมพ์** จะเปิด **หน้าต่างใหม่** — ต้อง **อนุญาตป๊อปอัป** สำหรับไซต์ `opec.co.th`  
- บางหน้ามีตัวเลือก **ภาษาในการพิมพ์ (ไทย/อังกฤษ)** สำหรับข้อความบนเอกสาร  
- เอกสารเป็น **สำเนาสำหรับพิมพ์ทางธุรกิจ** ตามที่ OPEC จัดรูปแบบไว้ — หากต้องการเอกสารประเภทอื่นตามสัญญา ให้ติดต่อฝ่ายบัญชีหรือผู้ดูแลโครงการ

---

## 9. สรุปภาพรวม Workflow

```text
เข้า opec.co.th → Login → พอร์ทัลลูกค้า
    │
    ├─ ใบเสนอราคา → อนุมัติ/ไม่รับ/ขอแก้ไข → พิมพ์ได้
    │
    ├─ Timesheet → ตรวจชั่วโมง (อ่านอย่างเดียว)
    │
    └─ การเงินและเอกสาร
           ├─ แท็บ ใบแจ้งหนี้: ใบเรียกเก็บ → ยืนยันยอด (ผู้อนุมัติ) / ทักท้วง → พิมพ์
           │                        ใบกำกับภาษี → พิมพ์ (หลังออกเอกสาร)
           └─ แท็บ ใบกำกับภาษี/ใบเสร็จรับเงิน: รายการรับชำระ → พิมพ์ซ้ำเมื่อมีลิงก์
```
